# Open Sans

Locally bundled variable WOFF2 fonts, normal style, weights 300–800.
Latin and Latin Extended subsets are loaded through `app/css/style.css` and
cached by the service worker for offline use.

Source: [Google Fonts CSS](https://fonts.googleapis.com/css2?family=Open+Sans:wght@300..800&display=swap), Open Sans v44.
